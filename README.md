# 声屿 · InGame Music

Minecraft **1.21.11 Fabric** 的纯客户端本地音乐播放器。Java 包名前缀为 `top.mc_plfd_host`。

音频使用随模组打包的 **纯 Java 解码器**，通过 Java Sound 输出。不依赖 FFmpeg、外部播放器、额外编解码器安装或在线服务。

![播放器界面（离屏渲染，使用演示曲目信息）](docs/player.png)

## 安装

1. 游戏使用 Minecraft **1.21.11**、Java **21**、Fabric Loader **0.18.4 或更新版本**。
2. 在客户端 `mods` 目录安装对应 **1.21.11** 的 Fabric API。
3. 将 `ingamemusic-1.0.0.jar` 放入同一 `mods` 目录。不要安装 `-sources.jar`。
4. 进入游戏后按 **M** 打开播放器。无需在服务器安装本模组。

模组的 `fabric.mod.json` 声明 `environment: client`，没有服务端入口。可选的语音音乐分享使用 Simple Voice Chat 自身的语音连接。

## 使用

| 默认按键 | 功能 |
| --- | --- |
| M | 打开音乐播放器 |
| P | 播放 / 暂停 |
| ] | 下一首 |
| H | 显示 / 隐藏音乐浮窗 |
| 右 Alt | 释放鼠标以操作、拖动迷你浮窗 |
| Esc | 关闭当前弹窗、取消输入焦点或返回游戏 |
| 空格 | 在播放器 / 迷你浮窗内播放、暂停 |

按键可以在游戏的 **选项 → 控制 → 按键绑定 → 声屿** 分类下修改；播放器设置页显示实际绑定的按键。输入文本时不会触发播放快捷键。

### 音乐文件与目录

- 点击“导入文件”，使用游戏内自绘文件浏览器选择文件或文件夹；文件夹双击进入。
- 路径栏支持粘贴任意可访问的目录路径，例如 `D:\Music`。Windows 可使用根目录按钮切换盘符。
- “音乐目录”支持添加多个目录、递归扫描、重新扫描和解除关联。
- 文件按真实路径去重，导入时不复制原音乐。再次扫描会刷新修改过的文件及标签。
- 音乐库内双击曲目或按 Enter 播放；右侧展示艺术家、作曲人、专辑及封面。
- 播放条支持音量调节、进度定位、上一首 / 下一首，以及顺序、列表循环、单曲循环、随机播放。
- 音量独立于游戏音量；如果不希望与原版背景音乐重叠，可调低游戏选项中的“音乐”音量。

### SimpleVoiceChatRedirect

- 在“偏好设置”开启 **SimpleVoiceChatRedirect**，本地播放的音乐会同时混入 SVC 语音，保留麦克风人声；默认关闭。
- **语音中的音乐增益**可在 **0–200%** 间拖动调整，默认 **35%**，独立于播放器本地音量与麦克风音量。0% 不发送音乐；较低增益更适合边说话边播放。
- 无需持续按语音键；**麦克风静音仍会分享音乐**。关闭本选项、暂停音乐或禁用 SVC 均会停止音乐发送。
- 需要客户端安装兼容的 Simple Voice Chat，并连接支持 SVC 的服务器；服务器无需安装本播放器。按 SVC 当前的附近 / 群组通道发送，接收范围遵循服务器设置。
- 开关与增益保存在播放器配置中。未安装 SVC 时仍可正常使用本地播放器，设置页会显示连接状态。
- 基于官方 `MergeClientSoundEvent` 接口，编译目标 API **2.6.13**（本地 SVC **1.21.11-2.6.16** 提供此版本）。音乐使用已有 Java 解码结果，在本地音量处理前转为 48 kHz 单声道并跟随播放设备时钟，不启动第二个解码器，不捆绑 SVC。

### 多选与歌单

- 单击选择，**Ctrl / Command + 单击**切换选择，**Shift + 单击**选择区间，**Ctrl / Command + A**选择当前列表全部曲目。
- 点击“我的歌单”旁的加号新建歌单。选中曲目后可“加入歌单”。
- 歌单支持创建、重命名、删除；歌单中的“移除”只移除引用。
- 搜索支持曲名、艺术家、作曲人、专辑和文件名。
- “全部音乐”中的“移除”只移除库记录，不删除磁盘文件；再次扫描目录会重新导入。

### 文件重命名与删除

- **F2** 或“重命名”直接修改选中文件的磁盘文件名。扩展名自动保留，音频标签保持原样。
- 批量重命名模板：`{name}` 为原文件名（不含扩展名），`{n}` 为从 `01` 开始的序号，例如 `{n} - {name}`。
- 重命名前检查冲突，禁止覆盖已有文件；更新音乐库及各歌单里的路径引用。
- **Delete** 或“删除文件”会弹出明确确认框。确认后，文件移入**原文件目录内**的 `.ingamemusic-trash`，并移除所有库和歌单引用。
- 回收目录中的 `.restore.json` 保存原路径。需要恢复时，将音频移回该路径并重新导入。回收文件不会被常规目录扫描再次导入。
- 操作正在播放的文件会先停止该曲目并等待解码器释放文件句柄。

### 游戏内浮窗

浮窗显示封面、曲名、艺术家、进度和音量电平动画。按右 Alt 后可拖动浮窗，点击上一首、播放 / 暂停、下一首、进度条，或点击右上角图标打开完整播放器。点击浮窗外侧或按 Esc 返回游戏。位置会自动保存。

在“偏好设置 → 浮窗样式”中选择“简洁”可缩小浮窗，只保留封面、曲名、艺术家、播放键和进度条。也可在浮窗右上角直接切换完整 / 简洁样式。

音乐库、歌单侧栏、目录、文件浏览器和歌单选择弹窗均支持带速度衰减的惯性滚动，保留触控板的小幅滚动量，反向滚动会立即制动。滚动条与内容共用同一连续位置；点击轨道平滑定位，拖拽直接跟随鼠标并取消惯性。滚动区域外不会误触列表滚动。

主界面采用顶部搜索与操作栏、左侧歌单、中间曲目列表、右侧专辑详情和固定底部播放条的布局；音乐库一次可完整显示 7 行曲目。

播放器及浮窗操作界面不会暂停单人世界。

## 格式支持与边界

| 文件 | Java 解码链路 | 说明 |
| --- | --- | --- |
| `.flac` | Java FLAC StreamDecoder | 支持高位深输入；输出转换为 16-bit PCM |
| `.aac` | JAAD | **ADTS 封装**；不是 `.m4a` / MP4 容器，也不支持 DRM |
| `.mp3` | Java mpg123 | MPEG 音频解码 |
| `.ogg` / `.oga` | Java Vorbis；检测到 Opus 时走 Opus 解码 | Ogg 音频容器 |
| `.opus` | Concentus + Vorbis Java 容器读取 | 48 kHz 输出，处理 pre-skip 和输出增益 |
| `.wav` | JDK Java Sound | PCM / Java Sound 可转换的 WAV 音频 |

当前播放器输出单声道或双声道、16-bit PCM。并非“位完美”无损音频设备输出；多声道文件不在支持范围。高采样率是否可输出也取决于系统 Java Sound 音频设备。

为兼容不同压缩格式，进度定位通过后台从起点解码并跳过 PCM 实现。定位长文件的后段时，可能显示“加载中”；文件不会整首载入内存。

标签由 jaudiotagger 读取。文件必须实际含有相应标签才能显示作曲人和专辑。封面优先使用内嵌图片，缺失时读取同目录的 `cover.jpg`、`cover.png`、`folder.jpg`、`folder.png`，最后使用自绘唱片占位图。裸 AAC 没有可识别标签时使用文件名和未知信息占位。

### 自动生成缺失封面

“偏好设置 → 自动生成封面”默认关闭。开启后，仅对缺失或无法读取封面的曲目生效：以音频文件内容的 SHA-256 哈希为种子，组合多层分形噪声、坐标扰动和随机局部旋涡，再进行高斯模糊，生成连贯、弯曲的色彩纹理。同一内容的文件即使重命名或移动，也会得到相同图案；修改文件内容后重新扫描即可更新。已有封面优先显示。新版使用独立的 `v2-` 缓存，不会继续显示旧版色块。

文件读取、哈希和生成均在后台执行，生成期间先显示唱片占位图；完成后同步显示在列表、详情、播放条及浮窗。生成结果缓存到 `config/ingamemusic/covers/generated/`，不会写入或修改音频文件。关闭开关后恢复占位图，保留缓存以便再次开启。

## 自绘 UI 与语言文件

主界面、按钮、输入框、设置卡片、弹窗和浮窗统一采用浅色主题：不透明的灰白底色、深色文字、青绿色强调色、细边框及弱渐变。面板内部只有轻微明暗变化，避免明显反光和透明叠色。

按钮和图标支持平滑悬停、按压反馈；导航与曲目行高亮渐变，输入框聚焦时显示柔和描边，进度条悬停显示定位点，音量滑块操作时显示强调光圈。动画按实际时间推进，叠加色和位置由 GPU 更新，避免为每一帧动画重新生成纹理。

面板材质、图标和封面在后台生成并缓存为纹理；文字的小纹理在首次使用时即时生成并缓存，避免文字变化时出现空白帧。文字按最终物理像素字号生成，并对齐像素绘制，减少缩放模糊。进度条与滚动条保留亚像素坐标，播放进度在音频设备的离散采样之间插值；暂停、换曲和定位会同步重置显示时钟。不会反复重绘、转换和上传整张窗口图片。Minecraft 的 `Screen` 仅承接输入及生命周期；界面不使用原版按钮、输入框、字体或背景。

所有自有界面、提示及错误文案放在：

- `src/main/resources/assets/ingamemusic/lang/zh_cn.json`
- `src/main/resources/assets/ingamemusic/lang/en_us.json`

游戏内通过 Minecraft 的翻译系统读取语言键，跟随游戏语言，并支持资源包覆盖。数量、路径等动态内容使用 `%s` 参数，不在 Java 中拼接自然语言。原始曲名、歌单名称、文件路径和第三方库返回的错误细节属于数据，不进行翻译。

### IMBlocker

自绘搜索框、路径框以及歌单 / 重命名输入框可对接 IMBlocker。仅输入框获得焦点时登记输入焦点，光标移动和界面缩放时同步候选框位置，离开界面时释放焦点。支持 IMBlocker 的字符模拟焦点检测，探测字符不会写入文本。

已针对用户提供的 **IMBlocker 6.0.3 Fabric（1.21.9+）** JAR 核对接口，并提供对应的可选离线 ABI 检查；同时兼容较新版本的候选框更新方法名。IMBlocker 为可选模组，不打包、不修改它或其配置，也无需将整个播放器加入输入法白名单。原生 Windows 输入法的实际候选窗行为仍需在游戏中验收。

```powershell
.\gradlew.bat build '-PimblockerTestJar=E:\HMCL\.minecraft\versions\LightingMC\mods\IMBlocker-6.0.3-fabric-1.21.9+.jar'
```

## 配置和缓存

```text
.minecraft/config/ingamemusic/
├── library.json        # 音乐库、目录、歌单、音量、播放模式、浮窗设置
└── covers/             # 缩放后的封面缓存；generated/ 保存自动生成的封面
```

配置使用临时文件加原子替换写入。损坏的配置会保留时间戳备份；请修复或移走损坏配置后重新启动。

## 构建与验证

Windows PowerShell（JDK 21）：

```powershell
.\gradlew.bat build
```

Linux / WSL 仅构建与离屏测试：

```sh
./gradlew build
```

产物在 `build/libs/`。依赖已经以独立嵌套 JAR 打包；无需手动下载 Java 音频库。

仅在 **Windows 原生环境** 进行游戏交互验收：

```powershell
.\gradlew.bat runClient
```

不要在 WSL2 / WSLg 中启动 Minecraft 进行本项目验证。

自动测试覆盖真实压缩数据的六格式解码、24-bit FLAC 逐样本转换、Opus 原始采样率提示与 pre-skip、音量计算、标签与内嵌封面、多选文件操作的数据层、路径冲突及回收目录、语言键完整性、Unicode 输入、滚动条拖拽、平滑滚动的帧率一致性与裁切命中、自动封面的确定性 / 模糊 / 开关 / 原封面优先、文字纹理边界、简洁浮窗场景和 IMBlocker 焦点协议。IMBlocker 协议测试使用隔离的测试接口，不调用系统输入法；指定 `imblockerTestJar` 时另行只读检查实际 JAR 的接口。测试音频由 Java 编码器与合成 ADTS 帧在临时目录生成，不包含商业音乐。

离屏界面预览输出到 `build/previews/`。它们用于检查自绘场景，不等同于实际游戏内操作测试。最终版本仍需在 Windows 原生 Minecraft 环境确认纹理显示、快捷键、浮窗拖动和设备音频输出。

SVC 测试覆盖跨解码块的重采样连续性、立体声混合、独立增益与限幅、播放时钟同步、断连 / 禁用 / 关闭开关时不发送、配置迁移与保存，以及未安装 SVC 时的类加载。构建时可传入 `-PvoicechatTestJar=/完整路径/voicechat.jar`，额外只读验证本地 SVC JAR 的插件事件接口；不启动 Minecraft 或发送语音。实际语音听感与人声混合仍需在 Windows 游戏中连接 SVC 后验证。

